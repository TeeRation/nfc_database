# NFC Database

Учебный проект для работы с NFC-метками, сотрудниками, местоположениями, устройствами и задачами.

Проект включает базу данных PostgreSQL, REST API на FastAPI, административную панель, минимальный веб-интерфейс и автоматические API-тесты.

---

## Используемые технологии

- Python 3.14+
- FastAPI
- SQLAlchemy
- PostgreSQL
- Alembic
- Pydantic
- SQLAdmin
- Pytest
- HTTPX
- HTML / CSS / JavaScript

---

## Создание виртуального окружения

В корневой директории проекта:

```powershell
python -m venv venv
```

Для активации в PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

Если PowerShell запрещает выполнение скрипта активации:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\venv\Scripts\Activate.ps1
```

После успешной активации перед строкой терминала появится:

```text
(venv)
```

## Настройка переменных окружения

Создать файл `.env` в корне проекта.

Пример подключения к основной базе данных:

```env
DATABASE_URL=postgresql+psycopg2://nfc_user:nfc_password@localhost:5432/nfc_database
```

Для автоматических тестов используется отдельная тестовая база:

```env
TEST_DATABASE_URL=postgresql+psycopg2://nfc_user:nfc_password@localhost:5432/nfc_database_test
```

Тестовая база отделена от основной, чтобы выполнение тестов не изменяло рабочие данные.

## Основные API-операции

### Определение местоположения по NFC-метке

```text
POST /api/location/resolve
```

Пример запроса:

```json
{
  "tag_id": "tag-1"
}
```

API находит NFC-метку, проверяет её состояние и определяет связанное с ней местоположение.

---

### Взятие задач в работу

```text
POST /api/tasks/start
```

Пример запроса:

```json
{
  "location_id": "location-1",
  "employee_id": "employee-1"
}
```

Подходящие активные задачи со статусом `planned` переводятся в статус:

```text
in_progress
```

---

### Получение текущего статуса задачи

```text
GET /api/tasks/{task_id}/status
```

Пример:

```text
GET /api/tasks/task-1/status
```

API возвращает текущий статус и признак активности задачи.

---

### Закрытие задачи

```text
POST /api/tasks/{task_id}/close
```

Пример запроса:

```json
{
  "employee_id": "employee-1"
}
```

Закрыть можно задачу, находящуюся в статусе:

```text
in_progress
```

После успешного закрытия задача получает статус:

```text
done
```

Также сохраняются сотрудник, закрывший задачу, и время закрытия.

## Автоматические тесты

Для тестирования API используется Pytest.

Запуск всех тестов:

```powershell
python -m pytest -v
```

На текущем этапе реализовано 9 автоматических тестов.

Проверяются:

- успешное распознавание NFC-метки;
- обработка резервной NFC-метки;
- успешное взятие задачи в работу;
- повторное взятие уже начатой задачи;
- получение статуса задачи;
- успешное закрытие задачи;
- повторное закрытие задачи;
- попытка закрытия от неизвестного сотрудника;
- запрос статуса несуществующей задачи.

Ожидаемый результат:

```text
9 passed
```

Тестовые сущности создаются через `pytest fixtures`, а тесты выполняются с использованием отдельной PostgreSQL-базы.
